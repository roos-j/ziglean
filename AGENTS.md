# Human-only files

The following files in this repository are considered human-only and may not be edited by agents unless explicitly instructed:

AGENTS.md
README.md
LICENSE.md
SOURCES.md
.gitignore

# Record keeping

Agents should record user instructions in their own words in `automation/instructions.md`.
Records must be brief, precise, time-stamped (US Eastern time, no seconds)
and numbered, starting with `R1`, `R2`, ..

# Commit conventions

- Create a git commit only when the user explicitly instructs you to do so.
  Permission to edit files does not imply permission to commit them.
- If a commit contains Codex-generated content, begin its subject with `[codex]`.
  For content generated by another agent framework, use the corresponding
  framework name in brackets.
- Keep the descriptive commit message to one subject line, no more than 150
  characters including the prefix. Do not add a descriptive body.
- After a blank line, include a `Co-authored-by:` trailer acknowledging the
  contributing agent. For Codex, use:

  ```text
  Co-authored-by: Codex <noreply@openai.com>
  ```

  For another framework, use its appropriate name and attribution address.
  Attribution trailers are separate from the one-line description.
